# arXiv Assistant Web UI

Локальный веб-интерфейс для управления библиотекой статей.

## 🚀 Запуск

### Быстрый старт

```bash
cd /Users/vitapotapova/.openclaw/workspace/arxiv-cli/ver-claude
./start-web.sh
```

Или вручную:

```bash
python3 web/app.py
```

Затем открой в браузере: **http://localhost:5000**

## 📱 Страницы

### 📚 Главная (/)
- Таблица библиотеки со всеми статьями
- Индикаторы статуса (✓/○/★)
- Теги и категории
- Поиск по библиотеке
- Клик на строку → детальная страница

### 📄 Детальная страница (/paper/:id)
- Полная информация о статье
- Авторы, категории, теги
- Аннотация
- Кнопки действий:
  - ✓ Отметить прочитанным
  - ★ Добавить в избранное
  - 📥 Скачать PDF
  - 🔗 Открыть на arXiv
- **Заметки:** добавление и просмотр

### 🔍 Поиск (/search)
- Полнотекстовый поиск по названиям, авторам, аннотациям
- Результаты с подсветкой

### 👥 Авторы (/authors)
- Список отслеживаемых исследователей
- Теги для категоризации
- Даты добавления и последней проверки

### 📊 Статистика (/stats)
- Общие цифры (всего, прочитано, избранное)
- Распределение по категориям
- Облако тегов

## ✨ Возможности

- ✅ Работает **без интернета** (локальная библиотека)
- ✅ Красивый дизайн (градиент, тени, анимации)
- ✅ Адаптивный (работает на планшете/телефоне)
- ✅ Быстрый поиск
- ✅ Заметки прямо в интерфейсе
- ✅ Экспорт BibTeX одним кликом

## 🛠️ Технологии

- **Backend:** FastAPI (Python)
- **Frontend:** HTML + CSS (без JavaScript frameworks)
- **Templates:** Jinja2
- **Server:** Uvicorn

## 📝 Использование

### Управление статусами

Открой статью → кликни на кнопку:
- **✓ Прочитано** / **○ Отметить прочитанным**
- **★ Избранное** / **☆ В избранное**

### Добавление заметок

1. Открой статью
2. Прокрути вниз к разделу "📝 Заметки"
3. Введи текст
4. Нажми "Сохранить"

### Экспорт

Кликни "Экспорт BibTeX" в меню → скачается файл `library.bib`

## ⚙️ Настройка

**Изменить порт:**

Отредактируй `web/app.py`, последняя строка:
```python
uvicorn.run(app, host="127.0.0.1", port=5000)  # Измени 5000 на другой порт
```

**Доступ из локальной сети:**

Замени `127.0.0.1` на `0.0.0.0` (небезопасно для публичных сетей!)

## 🎨 Кастомизация

CSS находится в `web/static/css/style.css`

Можешь изменить:
- Цвета градиента
- Шрифты
- Размеры

## 🔄 Синхронизация с CLI

Web UI использует **ту же библиотеку** что и CLI (`~/.arxiv-cli/library.json`).

Изменения в CLI сразу видны в Web UI (обнови страницу).
