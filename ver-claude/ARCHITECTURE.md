## 🤖 LLM в системе (сейчас НЕ используется)

### Где можно добавить LLM:

#### 1. **Дайджесты** (самое полезное!)

**Текущий:** Просто список статей  
**С LLM:** 
- Выбор топ-5 важных статей
- Группировка по темам
- Narrative дайджест

**Код уже готов:** `llm_digest.py` (только что создал!)

#### 2. **Summaries статей**

**Команда:**
```bash
arxiv summarize 1706.03762
```

**Что делает LLM:**
- Читает abstract
- Генерирует краткое резюме на русском
- Выделяет ключевые идеи

#### 3. **Q&A о статье**

**Интерактивный режим:**
```bash
arxiv chat 1706.03762
> Какая основная идея?
> Применимо ли к моей задаче?
```

**LLM:**
- Анализирует статью
- Отвечает на вопросы
- Сравнивает с другими работами

## 🔑 Как включить LLM:

### Настройка API ключа:

```bash
export OPENAI_API_KEY='sk-...'
```

Или в `~/.zshrc`:
```bash
echo 'export OPENAI_API_KEY="sk-..."' >> ~/.zshrc
```

### Использование:

```python
# В дайджестах
from arxiv_cli.utils.llm_digest import rank_papers_by_importance

digest = create_digest(period='week')
ranked = rank_papers_by_importance(digest['entries'], field='AGI')

# Теперь ranked[0] — самая важная статья по мнению LLM!
```

## 💰 Стоимость LLM вызовов

**Для дайджеста (~50 статей):**
- Ранжирование: ~$0.05 (GPT-4)
- Narrative digest: ~$0.10 (GPT-4)
- Summaries всех: ~$0.20 (GPT-4o-mini)

**Для одной статьи:**
- Summary: ~$0.001 (gpt-4o-mini)

**Вывод:** Дёшево! Можно использовать активно.

## 🎯 Предложение:

**Добавить LLM-дайджест как опцию:**

```bash
# Обычный дайджест (без LLM, бесплатно)
arxiv digest --period week

# LLM-дайджест (топ-5 важных статей)
arxiv digest --period week --ai-rank

# Полный narrative дайджест
arxiv digest --period week --ai-narrative
```

**В Telegram:**
```
/digest          → обычный
/digest_ai       → с AI ранжированием
/digest_story    → narrative версия
```
